# Organizer checklistit

Askel askeleelta -ohjeita järjestäjälle. Ero playbookeihin: playbook kuvaa konseptin ja toimintamallin, checklist kertoo mitä järjestäjän pitää tehdä missäkin järjestyksessä.

## Yhteinen rakenne

Jokaisessa checklistissä on: `Ennen`, `Julkaisu`, `Viimeinen viikko`, `Tapahtumapäivä`, `Tulokset`, `Jälkihoito`, `Avoinna`.

## Käyttö

Käytä checklistiä järjestäjän muistilistana. Linkit ja assetit haetaan erikseen (linkkirekisteri), niitä ei ole valmiiksi näissä checklisteissä. Jos kohta on merkitty avoimeksi, vastuuhenkilö vahvistaa nykytilan ennen kuin sitä käytetään tuotannossa.
